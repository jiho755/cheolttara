# 철따라 — 제철 데이터 명세 (v1)

출력 파일: `seasonal_items.json` — 항목 객체의 JSON 배열 (UTF-8, 들여쓰기 2칸)

## 항목 필드
| 필드 | 타입 | 규칙 |
|---|---|---|
| id | string | `{category}-{영문슬러그}` 예: `food-strawberry`. 중복 금지 |
| name | string | 한국어 이름. 예: "딸기", "벚꽃 구경" |
| category | string | `food` / `nature` / `event` 중 하나 |
| subcategory | string | food: 과일, 채소, 수산물, 해조류, 곡물·견과 / nature: 꽃, 단풍, 풍경, 생물 / event: 절기, 명절, 세시풍속, 계절놀이 |
| emoji | string | 대표 이모지 1개 |
| start | object | `{"month": 1~12, "period": "early"|"mid"|"late"}` (초순/중순/하순) |
| end | object | start와 같은 형식. end.month < start.month 이면 해를 넘기는 항목 (예: 12월→2월) |
| summary | string | 한 줄 설명, 40자 이내 |
| tip | string | 즐기는 팁 한 줄, 60자 이내 |
| region | string | "전국" 또는 "중부 기준" (꽃·단풍처럼 지역차 큰 것은 "중부 기준") |

## 구성 (총 100개)
- food 60개: 과일 15, 채소 18, 수산물 20, 해조류 4, 곡물·견과 3
- nature 30개: 꽃 14, 단풍 4, 풍경 6, 생물 6 (예: 반딧불이, 철새)
- event 10개: 매년 반복되는 것만. 특정 지역 축제·날짜가 해마다 바뀌는 행사 금지
  (예: 동지 팥죽, 정월대보름 부럼, 김장, 단오, 첫눈, 해돋이 등)

## 품질 규칙
- 한국(국내산, 노지 기준) 제철 시기를 쓴다. 하우스 재배 출하 시기 아님
- 1년 내내 나오는 것은 제외 (예: 사과처럼 저장 유통되는 경우 '수확 제철'로 한정)
- 열두 달 모두에 최소 5개 이상 항목이 걸치도록 분포
- 확신이 낮은 항목은 넣지 말고 확실한 대체 항목을 넣는다
